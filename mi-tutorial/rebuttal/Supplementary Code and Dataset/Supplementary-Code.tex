\section{Multiple imputation for derived
covariates}\label{multiple-imputation-for-derived-covariates}

In this section, we impute missing BMI from missing weight and height
using the three options illustrated in our manuscript. We use the boys
dataset from the \emph{mice} package, which contains data on the growth
of Dutch boys, with 748 rows and 9 variables, including BMI, weight, and
height, which were missing. More information about the dataset can be
found by using the command ?boys.

\subsection{Impute, then transform}\label{impute-then-transform}

We impute any missing height and weight data, and append BMI to the
imputed data afterward. BMI is not a predictor in the imputation model
in this case.

\NormalTok{matrix[,}\StringTok{"bmi"}\NormalTok{] }\OtherTok{\textless{}{-}} \DecValTok{0}
